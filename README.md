# open-source-core

The J. C. J. Foundation's shared base for its open-source desktop apps: the app shell, project
files, format conversion, cards and boards, theming and agent control, built on
[WordCraft](https://github.com/storytold/wordcraft) and
[craft-libs](https://github.com/storytold/craft-libs) through the foundation's own forks.

Work in progress: see `docs/` as it lands.
